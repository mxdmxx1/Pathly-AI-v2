# User Journey

1. **Discover:** Student understands that Pathly supports VCE and VCE VM learning and future planning.
2. **Register:** Student creates an account through a secure, age-appropriate flow.
3. **Onboard:** Select pathway, year, subjects/learning areas and optional interests. "I'm still exploring" remains available.
4. **Personalise:** Dashboard presents a manageable starting point.
5. **Learn:** Student completes a lesson and checks understanding.
6. **Get help:** AI assistant offers explanations, hints or examples while supporting independent thinking.
7. **Practise:** Student attempts questions and reviews explanations.
8. **Track:** Progress updates and suggests a reasonable next step.
9. **Explore:** Student compares post-school routes using verified official information.
10. **Adapt:** Student can change subjects, interests and goals over time.
