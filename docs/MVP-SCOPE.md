# MVP Scope

## Objective
Test whether a focused Pathly experience solves meaningful problems for VCE and VCE VM students before expanding into a large platform.

## Proposed first release
1. Secure registration and student profile.
2. VCE/VM onboarding, year level and subject selection.
3. Personal dashboard.
4. A small set of structured learning paths.
5. Lesson completion and basic progress tracking.
6. Subject-aware AI study assistant with usage limits.
7. Small practice set with explanations.
8. Basic pathway explorer using verified official links.
9. Small curated resource library.
10. Responsive mobile-first web experience.

## Pilot content candidates
Possible VCE subjects: English, General Mathematics and Mathematical Methods.

Possible VCE VM learning areas: Literacy, Numeracy, Work Related Skills and Personal Development Skills.

These are hypotheses, not final scope. Validate them with students and educators before committing.

## Defer
- Native iOS/Android apps.
- Every subject and learning area at launch.
- Full-length mock exam system.
- Public social feeds or community features.
- School administration dashboards.
- Automated official assessment grading.
- Complex recommendation algorithms.

## Acceptance criteria
A pilot student can register, complete onboarding, receive a relevant dashboard, complete a learning module, ask a curriculum-relevant question, attempt practice, explore a real post-school option through an official source and view basic progress on a phone.

## Release gates
Review content accuracy, AI limitations, privacy notices, consent, database access policies, accessibility, mobile usability and operating costs before broad release.
