# Development Roadmap

This is a proposed sequence, not a guaranteed delivery schedule.

## Phase 1 — Validate
- Interview VCE and VCE VM students.
- Speak with educators/careers practitioners where possible.
- Identify repeated pain points.
- Select a narrow pilot scope.

## Phase 2 — Prototype
- Create the design system and core screens.
- Prototype onboarding, dashboard, learning, AI support, practice and pathways.
- Test on phones and revise based on observation.

## Phase 3 — Foundation
- Build the responsive web app.
- Implement authentication, profiles and database access policies.
- Establish navigation and reusable components.

## Phase 4 — Learning
- Implement a small content model.
- Add lessons, practice and completion tracking.
- Add basic progress summaries.

## Phase 5 — AI
- Integrate AI through secure server-side routes.
- Add curated curriculum context, limits and safety checks.
- Evaluate accuracy and teaching quality.

## Phase 6 — Pathways
- Build a curated, source-backed pathway catalogue.
- Record source URLs and review dates.
- Verify requirements with official providers.

## Phase 7 — Pilot
- Recruit a small tester group with appropriate consent.
- Test usability, accessibility, accuracy, privacy and costs.
- Fix issues before expanding.

Build the smallest experience that proves value. Do not attempt every subject, exam and pathway database before testing with students.
